# MyTools — Decision Support

Dokumen ini mencatat desain fitur analisis dan pendukung keputusan yang menjadi bagian dari aplikasi MyTools.

- `PRODUCT_DECISION_ASSISTANT_SPEC.md` — kebutuhan data, analisis ulasan, rekomendasi, dan alur pengguna. Istilah lama pada nama dokumen dipertahankan sebagai sumber spesifikasi; nama modul dan route implementasi adalah `decision_support`.
- `ARCHITECTURE_DAN_STRUKTUR_FOLDER.md` — contoh arsitektur dan pemisahan folder yang menjadi acuan struktur project.
- `PRODUCT_DECISION_ASSISTANT_INTEGRATION_PLAN.md` — struktur implementasi yang saat ini digunakan dalam repository.
- `PRODUCT_DECISION_ASSISTANT_REPOSITORY_AUDIT.md` — audit kondisi awal sebelum restrukturisasi.
